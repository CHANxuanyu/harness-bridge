# Harness Bridge

> **Experimental prototype — bootstrap stage (M0).** Nothing here is production-ready.
> No real Claude Code / Codex run has been performed through this bridge.

Harness Bridge turns "delegate a coding task to another agent harness, collect evidence,
request repairs, recover from interruptions" into a recorded, testable local protocol.
It is a deterministic local CLI (`hbridge`); it never calls a model API itself.

See `STATUS.md` for what is implemented and verified right now.
